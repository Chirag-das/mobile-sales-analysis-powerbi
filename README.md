# 📱 Mobile Sales Analysis Dashboard | Power BI

## 📌 Project Overview

The **Mobile Sales Analysis Dashboard** is an interactive Power BI project designed to analyze mobile phone sales performance across brands, cities, payment methods, and time periods.

The dashboard transforms sales data into meaningful visual insights, helping users monitor key performance indicators (KPIs), compare brand performance, explore monthly trends, and evaluate year-over-year performance.

This project demonstrates my practical skills in **Power BI, data visualization, DAX, and business analysis**.

## 🎯 Business Problem

Businesses need to understand how their mobile sales are performing across different brands, locations, payment methods, and time periods. Analyzing raw sales data manually can make it difficult to identify trends and compare performance.

This project addresses that challenge through an interactive dashboard that presents key metrics and sales patterns in an easy-to-understand format.

## 🎯 Project Objectives

- Analyze overall mobile sales performance.
- Compare sales across mobile brands.
- Explore sales trends across months and years.
- Understand the distribution of payment methods.
- Compare current-period performance with the same period in the previous year.
- Monitor key sales KPIs through interactive visualizations.
- Generate actionable business questions and recommendations from the data.

## 🛠️ Tools and Technologies

- **Microsoft Power BI Desktop** — Dashboard development and data visualization
- **DAX (Data Analysis Expressions)** — Measures and KPI calculations, where applicable
- **Power Query** — Data preparation and transformation, where applicable
- **Data visualization** — KPI cards, charts, tables, and slicers

## 📊 Dashboard Pages

### 1. Mobile Sales Dashboard

The main dashboard provides an overview of mobile sales performance.

Key elements include:
- Total Sales
- Total Quantity
- Total Transactions
- Average Price
- Brand-wise sales comparison
- Payment-method distribution
- Monthly quantity trends
- Interactive filters and visualizations

### 2. Month-to-Date (MTD) Report

The MTD report focuses on performance within the current month up to the selected date.

It helps users:
- Monitor month-to-date performance.
- Review sales trends during the month.
- Track relevant KPIs for the selected period.

### 3. Same Period Last Year Report

This page supports comparison between a selected period and the corresponding period in the previous year.

It helps users:
- Evaluate year-over-year performance.
- Identify changes in sales trends.
- Investigate periods with increases or decreases in performance.

*The accuracy of time-based comparisons depends on the date table, relationships, measures, and selected filter context.*
